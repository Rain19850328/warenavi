창고네비 플레이오토 전송기 (사무실 PC용)
==========================================

왜 필요한가
  플레이오토는 등록된 IP(사무실 121.142.255.30)에서만 API 요청을 받는다.
  창고네비 서버는 클라우드에 있어서 직접 보낼 수 없다. 그래서
  실사반영에서 '반영'하면 '전송 대기'로만 남고, 사무실 PC의 이 전송기가
  1분마다 대기 건을 가져와 플레이오토 실재고를 고친 뒤 결과를 기록한다.

처음 설치 (사무실에서 항상 켜 두는 PC 1대)
  1. Python 3 설치 (python.org, 설치할 때 "py launcher" 포함). 추가 패키지는 없다.
  2. 이 tools 폴더를 PC에 둔다.
  3. playauto_worker.env.example 을 같은 폴더에 ".env" 로 복사하고 값을 채운다.
     - SUPABASE_SERVICE_ROLE_KEY: Supabase 대시보드 > Project Settings > API > service_role
       (모든 데이터에 접근 가능한 키다. 이 PC 밖으로 옮기지 말 것)
     - PLAYAUTO_*: GitHub Secrets 에 등록된 값과 같다.
  4. 점검: 명령 프롬프트에서  py -3 playauto_worker.py --once
     "대기 건 없음" 또는 "전송 완료 N건" 이 나오면 정상.
  5. run_playauto_worker.bat 을 실행해 둔다(창을 닫으면 멈춘다).

PC를 켤 때 자동으로 시작하기
  작업 스케줄러 > 기본 작업 만들기 > 트리거 "로그온할 때"
  > 동작 "프로그램 시작" > run_playauto_worker.bat 선택.

상태 확인
  창고네비 실사반영 탭 상단에 "사무실 전송기 정상 (N분 전 확인)" 이 보인다.
  10분 넘게 응답이 없으면 빨간 글씨로 바뀐다.
  자세한 기록은 tools\playauto_worker.log.

알아 둘 점
  - PC가 꺼져 있던 동안의 반영 건은 켜지면 자동으로 보내진다.
  - 플레이오토 로그인이 막히면(IP 변경 등) 5분마다 다시 시도하고, 화면에 오류가 표시된다.
    KT IP가 바뀌면 플레이오토에 새 IP를 다시 등록해야 한다(고정 IP 신청 권장).
  - 실패한 건(SKU 없음 등)은 화면의 "플레이오토 다시 전송"을 누르면 다시 대기로 들어간다.
